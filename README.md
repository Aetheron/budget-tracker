# Budget Tracker
## Prerequisites
Node.js v18+
yarn
## Setup
### Install dependencies
`cd server && yarn install`
`cd ../client && yarn install`
## Run the app
Terminal 1 (backend): `cd server && yarn dev`
Terminal 2 (frontend): `cd client && yarn dev`
Open http://localhost:5173

## Notes
It is recommended to use VSCode with the Prettier extension installed to ensure files are formatted properly on save.
